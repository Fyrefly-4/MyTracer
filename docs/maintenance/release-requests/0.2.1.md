# v0.2.1 发布请求

本记录只请求下一张 Release Please 发布 PR，不代表 v0.2.1 已发布，也不授权自动合并发布 PR。

## 请求范围

- 目标版本：`0.2.1`。将已合入 main 的 [#80](https://github.com/Fyrefly-4/MyTracer/pull/80) 发布检出与测试隔离修复纳入新的发布源；不增加业务功能或调整超时测试。
- 保留既有 `v0.2.0` tag、草稿和固定源 SHA，不把最新 main 混入旧版本，不删除或覆盖旧发布记录。
- 由 Release Please 生成版本文件及 changelog；本请求不手工修改它们，也不设置持续生效的版本覆盖配置。

## 合入与发布

1. 合入本请求时，最终 squash commit 标题使用 `chore: request release 0.2.1`，正文必须保留独立一行 `Release-As: 0.2.1`。文档内容本身不是 bot 指令，不能只把该字段留在评论中。
2. 等待 bot 创建 `0.2.1` 发布 PR，核对版本文件一致及最新 head 的 `CI Gate`。如果正文指令丢失或 bot 未创建 PR，先排查，不手推 tag 或修改旧草稿来替代。
3. 由 owner 决定何时合并新的发布 PR；只有该次合并才进入验证、打包和发布流程。真实发布及本地更新仍需届时验证。

具体规则见[发布维护](../RELEASE.md#手动指定下一版本)。
