# #124 A：只读记录册实施方案

基线：main `3f1975b402016da036505b2878716f223d55a197`，已包含 PR140 的历史检索。用户已批准 A 的月度阅读原型及 Progress 更多 / 数据导出入口。本方案不激活阶段工作流。

## 范围与接入

保留原生 Mica 外壳、标题栏和主导航；由两个次级入口打开主内容阅读页，返回恢复来源筛选、选择和滚动，沿用草稿保护。只保存会话中的阅读月份与位置，首次选择最新有记录月份；进入和返回时读当前已保存资料，阅读途中不自动重排。

以既有一致性核心快照生成明确类型的阅读模型。行动、例行按 occurredOn，复盘按 periodStartedOn 分组；不通过 UTC 转换发生日。连续日节、紧凑年份目录、一个活动月份、相邻有记录月份和直接跳转。暖象牙色 / 鼠尾草色及排版须检查批准 HTML 后落实，品牌使用仓库 Origin Logo / C1 wordmark。

原备注、结果、未知时长与零时长、记录时下一步、理解（含撤销）、困惑（含解决说明和状态）保留。当前标题、关联及状态显式标为读取时现状，不声称历史快照。复盘只展示原文。无 AI 总结、成长评分或章节评价。

未形成日期记录的目标、行动、例行，以及日程、今日选择等不塞入虚构发生日；列出未收录范围与数量。完整 JSON 继续作为独立权威结构化导出，意义及兼容性不变。

## 文件交付

默认全书 HTML，保留所有月份和内部导航，与应用共用阅读模型和样式。固定导出时间、范围及排除项，不宣称备份或恢复验证。转义所有用户文字，不内插可执行脚本，不引用网络、分析或远程字体。通过最小具体 IPC 和现有临时文件 / 回读 / 目的地保护交付，不让 Renderer 接触文件系统。

不新增实体、schema、依赖、云同步、导入或恢复；B 延期于 #139，C 不在范围内。

## 验收与证据边界

- 模型：空资料、缺失/未知/零字段、全部结果及状态、理解/困惑、复盘、未收录数量；跨年、时区边界、密集月份与长文字。
- 输出：恶意闭合 script、属性和 HTML 字符；全书内容覆盖，内部导航，无外部资源，固定时间。
- 交付：重复取消、失败后重试、目的地变化、回读失败，不误报成功，不影响 JSON。
- UI：入口、单月与跳转、来源返回/滚动、查看原记录、草稿、读取失败和过期异步响应；窄窗、缩放、键盘。
