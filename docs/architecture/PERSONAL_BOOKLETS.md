# 编选留念小册子

用户于 2026-10-28 确认小册子及开始实现，并单独批准本轮最小 schema 迁移。基于 main `4f74fcf2798a2e33e01002cc383a2aab07b4cff2`，不包含其他实验分支。

## 使用与内容边界

“数据 → 阅读记录册 / 保存 HTML → 编选小册子”提供创建、加入行动记录或独立想法、阅读、上移/下移、移出、导出及删除整册。标题和自己的话均可留空；不要求总结或成长结论。每册同一来源只加入一次，可以继续添入其他来源。没有章节、封面系统、自动精选、AI、提醒、同步或通用导入。

小册子只保存有序引用。进入、返回、重新读取或重新聚焦窗口时（无编辑/加入/来源会话）读取当前保留的原文；阅读期间不是实时订阅。来源修改后下次读取显示新原文，导出始终重新读取数据库，不使用 Renderer 候选缓存。加入时重新验证来源存在，打开来源时再次核对引用。读取失败隐藏旧正文并提供重试，不把失败解释为已删除。

整页单栏承载长文，原文保留换行并折行。加入候选有文字/日期筛选与独立页面，刷新或加入后保留该页。来源返回读取当前册子；想法只显示对应条目，行动使用原有严格来源详情。输入仅在显式保存时写入，取消会丢弃；忙碌时同步锁阻止重复提交。

移出仅移除引用。源经单记录、独立想法、行动或目标正常删除后，所有相关册子保留“来源已删除”位置，数据库仅保留引用 ID 和种类，不保留正文或旧来源 ID。位置可再移除；删除整册只删除其引用。已有导出文件不受后续源/册子删除影响。册子与引用不进入行动统计或 AI 上下文。

## 持久化与并发

schema 10 新增 `booklets` 与 `booklet_entries`。引用有独立 ID、册内位置、来源种类和两个互斥的可空外键。外键 `ON DELETE SET NULL` 覆盖任意正常级联删除路径，多册引用同时失效；不会阻止原删除。册子外键 `ON DELETE CASCADE` 只处理引用。没有新增历史正文、事件系统或撤销归档。

Application 在事务中验证并保存整册引用顺序。`revision` 乐观核对避免旧排序覆盖新排序；源删除通过触发器增加受影响册子的 revision，旧引用不能恢复已删除源。重复提交同一结果返回现存册子；不同结果的过时版本拒绝并要求重读。失败事务回滚标题和引用列表。Renderer 不乐观重排；保存成功后读取权威顺序。标题最多 200 字、自己的话最多 4000 字、每册最多 1000 条，用于限制输入和 IPC 负载。

已有数据库升级前沿用 `VACUUM INTO` 完整备份和完整性检查，v9 的后缀为 `before-personal-booklets-v10-<uuid>.sqlite3`；更旧数据库保留原最早升级点命名。按版本事务迁移、重复启动不重复备份。旧版最高支持 schema9，不能打开 schema10；无降级、自动恢复或合并能力，不将升级后的 profile 交给旧版本。

完整 JSON 升为 v8 / sourceDataVersion10，`data.booklets` 必需，包含册子元信息和按用户顺序排列的引用。它与所有源记录在既有 `readCompleteCoreSnapshot` 的同一个 SQLite 事务读取。验证拒绝缺字段、重复引用/ID、错误类型、无效版本/时间、非空悬空来源及额外缓存正文字段。历史 v1–v7 的验证分支保持独立，不静默转换历史文件。

HTML 在导出调用时从同一事务读取册子和现存来源，再交付独立 UTF-8 文件；对话框打开后的源变化不改写这个已捕获版本。仅此导出副本定格。HTML 按册内顺序转义用户文字，使用禁止脚本和外部资源的 CSP；长文可离线阅读/打印。文件沿用独占临时文件、flush、回读验证、目标变化检测和原子交付。HTML 不是完整数据备份。

## 合成验证与人工步骤

自动测试使用临时库、FakeClock 和合成文字，覆盖多册引用、单源/行动/目标级联删除、独立想法删除、失败回滚、重复提交、旧排序冲突、删除后加入拒绝、原文修正、导出定格、严格 IPC/JSON、迁移回滚和升级前备份。Electron 场景要求保留 sandbox。

在独立临时 profile 中人工检查（不使用私人库）：

1. 新建无标题册子，再修改标题/自己的话。加入长行动记录和多段独立想法；继续加入时页面不跳回原文。
2. 窄窗/高缩放阅读，验证全文换行、滚动、排序与按钮可达。回到两个类型的来源修改后返回，应显示当前原文。
3. 两个册子引用同一来源，分别通过记录、行动和所属目标删除，再删独立想法；所有对应位置都显示已删除，不显示缓存正文。
4. 快速重复保存/加入/排序；模拟失败及旧视图排序，不应重复或覆盖新顺序。失败输入保留，重新读取可恢复。
5. 保存 HTML 后修改/删除来源，离线打开旧文件仍保留导出内容。删除整册后源仍在，完整 JSON 含所有册子与删除位置。
6. 用合成 schema9 库升级、重启，检查备份与保留内容。不要用升级后的库运行旧版。

Windows CI 的自动通过不替代字体、窗口材质、键盘/辅助技术与实际长文舒适度的人工验收。Linux 缺少 Windows 工具或沙箱宿主支持时如实报告，不关闭 Electron sandbox。
