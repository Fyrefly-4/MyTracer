# 独立想法

2026-10-28 用户批准独立想法及其最小数据结构/安全迁移。本次从 main 独立演进，参考 #139 与 #125 B2 的方向，不实现目标关联或转换流程。

## 保存即成立

想法只有正文、明确的本地日期和创建/修改时间，无标题、目标、行动、时长、推进状态或待处理标记。一句或一段即可保存。空白拒绝，正文为纯文本，长文保留换行并自动折行。它不贡献行动次数、投入时长、目标活跃度、复盘事实或热力图亮度，也不进入 AI 上下文。

“今天”的“当天独立想法”可写入、读取、修改；首页“留下的痕迹”按日展开时，想法以独立区块随当日行动/例行记录一起回看。首页有“查看今天的记录与想法”入口。所选日期明确显示，历史日写入由用户显式选择，未来日期拒绝。午夜后已打开的编辑器保留显示的日期，保存不会偷偷改成另一日。

阅读取舍：今天沿用既有左栏宽度，长文会折行，但阅读空间较窄；本轮不扩展布局。需要展开阅读时，可使用首页日历的当日区块或记录册。

输入不自动保存，也不做持久草稿。取消、切换日期或离开该页会丢弃未保存输入，界面有明确提示；返回只读取已保存资料。显式保存时按钮锁定且有同步防重锁；同一次创建 ID 重试只得到原条目，失败保留输入。修改核对先前正文，冲突不覆盖。删除先展示完整正文和永久删除 1 条的影响，用户确认后在事务内再次核对正文；无关联级联删除。

## 数据与边界

领域 `Thought` 不依赖 UI、Electron 或 SQLite；Application 命令在事务中执行。独立 SQLite repository 提供持久化；Renderer 只调用四个具体 typed API，Main 校验 sender、参数形状、ID 和日期/正文。没有新依赖、服务、数据空间、导入流程或真实凭据。

schema 9 仅新增 `thoughts` 表及日期索引，既有资料不重写。空库顺序迁移；已有库升级前 `VACUUM INTO` 生成完整本地备份并执行完整性检查，v8 备份后缀为 `before-standalone-thoughts-v9-<uuid>.sqlite3`（更旧库沿用原 v8 备份命名）。迁移按版本事务执行，重复启动不重复迁移/备份。备份含本机原资料，不能作为测试附件上传。

这是一项前向迁移。旧 main 最高支持 schema 8，会拒绝打开 schema 9；本次不实现降级、不绕过版本检查，也不宣称旧版安全。升级后不得把同一 profile 切回旧 main 或其他 schema 8 分支。旧备份不包含升级后新写入内容，自动恢复/合并未实现。

## 导出、阅读与暂未覆盖的触点

完整 JSON 升到 v7 / sourceDataVersion 9，必须包含 `data.thoughts`（包括空数组），稳定按日期和 ID 排序，完整正文与时间保留；缺字段、重复 ID、空白或无效日期会拒绝导出。历史 JSON v1–v6 验证器继续支持原格式，不静默升级或删字段。

只读记录册及全书离线 HTML 包含“独立想法”原文，按其本地日期编排，文本转义，不显示行动状态。HTML/JSON 可读不等于恢复已经验证。

现有“数据”行动/例行检索、进展、复盘与最近行动卡片不展示独立想法；没有增加全局想法检索。首页日历仍只统计行动/例行，文案说明想法需按日展开。首页日历目前最长半年；更早想法可在记录册阅读，也可从“今天 → 当天独立想法 → 回看想法日期”选择过去日期进行读取、修改和删除。

## 独立实机验收

使用独立临时 profile 和合成资料，不打开私人库。保持 Electron sandbox 开启，勿使用 `--no-sandbox`。构建后使用现有临时根测试工具或在专用测试操作系统用户下启动此分支，确认数据根与正式 profile 分开。

1. 首页点击“查看今天的记录与想法”，留一句想法；验证无标题/目标必填，空白禁存，快速重复保存只有一条。
2. 写多行长文及 `<script>` 字样；查看换行、窄窗口滚动及纯文本显示。修改后保存，重启仍保持。
3. 修改后取消；新输入后切页返回；都不应新增/修改已保存资料。检查明确保存失败时输入仍在，重新读取后冲突不覆盖。
4. 从“今天 → 当天独立想法”查看同一条；首页选择另一日，确认日期隔离。删除预览取消保留，确认仅删除该想法。
5. 在仅有想法的日子确认日历亮度、行动次数、时长、目标进展没有改变。记录册和 HTML/完整 JSON 均应包含想法。
6. 用合成 v8 数据库启动，验证旧对象/记录保留、产生升级前备份、再次启动不重复。不要用升级后的 profile 启动旧版。

自动测试不代替 Windows 字体、窗口材质、键盘/屏幕阅读器、长文阅读舒适度和真实 Electron 手工验收。
