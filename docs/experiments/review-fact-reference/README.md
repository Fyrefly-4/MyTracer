# 事实辅助复盘：原型实验

本实验由用户授权，基于 main `27762b2f5d041071baa509f4d48c09f13c4580a5` 独立开发，不叠加目标页 PR #95。目标是让用户在自己的复盘文字和已有事实之间往返，不生成结论、不自动填入、不评分。

## 观察与方案

同一份隔离合成资料含 25 条行动记录和 25 条理解。1120 × 760、100% 下，原页表单顶部在 y=6789 CSS px，主内容高 7438 px；写作前需要穿过整段事实。实验把写作放到事实列表前，桌面并列呈现有限高度的参考区，窄窗口上下排列并提供持续可达的「前往填写／查看参考事实」。相同资料的表单顶部降至 y=414，主内容高 939 px。这里只测量布局位置，不把它解释为用户效率提升的统计证明。

| 情况 | 原表单 y | 实验表单 y |
| --- | ---: | ---: |
| 1440 × 900，100% | 6555 | 414 |
| 1120 × 760，100% | 6789 | 414 |
| 820 × 650，100% | 6944 | 542 |
| 1120 × 760，125% | 6911 | 519 |

820 × 650、125% 首屏仍不能完整展示表单，但「前往填写」已经可见；按下后直接聚焦第一个文本框。100 条记录、长标题、150% 下也实测了跳转、聚焦和独立滚动，不通过缩小字号换空间。

## 实际交互

1. 用户从行动、例行、理解或未解决困惑中明确「选择作参考」。选择只改变预览。
2. 用户选择三个既有复盘段落之一，再按「追加引用到草稿」。引用包含日期、事实类型、标题和事实文字；原有文字保持原样。相同完整引文在同一段落只追加一次，可自行编辑或删除。
3. 重新读取后，所选事实变化或缺失时暂停引用、提示重新选择；已经写入的文本不会被回写。引用是保存时的文字快照，不是永久关系链接。相同文字的不同记录会被保守地视为重复引文。
4. 导航去看完整记录再返回，未保存草稿在本次应用会话中保留；不新增磁盘草稿格式。正常保存复用现有 DTO 和命令，重启后读取已保存结果。
5. 新周期不会承接旧草稿：提示保留文字以便复制，用户可明确放弃再进入新周期。读取未完成或失败时填写暂时锁定，避免错周期保存。
6. 保存请求未完成时返回复盘页，等待结果再恢复编辑；成功提交的「创建并使用」不会留作待执行命令。较晚返回的旧取消／后续读取不会清除新编辑。

## 验证与取舍

- 新增 3 个单测与 8 个 Electron E2E：显式选择、不覆盖、不重复、指定段落、真实保存重载、刷新变化／缺失、0／25／100 条、长标题、1440／1120／820、100／125／150%、独立滚动、聚焦、减弱动画偏好、跨周读失败、晚到响应、实际创建后再次保存不重复创建。
- Linux 上原有复盘结果／摘要 3 项 E2E 通过；仅在临时副本添加 headless 启动参数，未改动原测试。
- typecheck、lint、build 通过。完整本地单测 497 通过、1 项 Windows npm.cmd 测试失败；完整 integration 169 通过、10 跳过、23 项发布工具相关测试失败（Linux 缺少 powershell.exe 等 Windows 环境）。对应 Windows CI 结果记录在本 PR。
- 独立审阅发现并推动修复：初始化失败时误用周期、晚到响应覆盖新草稿、已提交创建动作重放；最终静态复核无剩余具体阻塞。
- 双滚动区需要用户适应；窄窗口使用上下区块与跳转，不扩展全局布局。事实仍全部载入，只有展示高度有界，不声称大数据虚拟化。
- 未保存草稿仅存于内存，不能抗应用崩溃；跨页保留会参与现有未保存内容检测。字体、milk green、Original 6 标识、MicaStrong 以及其他页面双栏均不改。
- Windows 本机的字体、MicaStrong、真实触控板／键盘和屏幕阅读器人工验收待完成。没有合并、发布、接触真实数据或使用额度重置卡。


## 第二轮实际使用：长来源引用区修复

在原型 head `89380da` 上，25 条长标题记录和多段理解暴露出选中状态的布局退化：820×650、150% 时，来源标题在说明和引文里重复，选中区393 CSS px高于整个303px参考面板；追加按钮顶部 y≈475，超过433px视口。1120×760 时事实浏览区只剩104px。原自动化覆盖了长列表，但未断言选中长事实时的几何边界；本次补齐。

修复把引用目标与动作放在预览前，正文独立有界滚动；「查看来源与完整引文」原生折叠区支持 Enter/Space，保留完整日期、来源标题及正文。预览使用独立 text 字段，保存 citation 字节内容不变。来源变化／缺失提示留在预览区域，继续禁止追加。短内容视口选中参考后允许面板使用90dvh，为正文保留空间；外层仍可滚动，非全局布局变更。

实测820×650、150%：按钮顶部降至 y≈236；面板 scrollHeight 与 clientHeight 均为389px，无内部溢出，事实浏览区保持100px。较长外层面板是明确取舍，优先保证引用控件与正文可达。不在本次补丁加入分类跳转。

## 收敛复核：跨周旧草稿的键盘复制

静态复查发现旧周期提示「先复制文字」，但无有效context时整个fieldset禁用，导致键盘无法聚焦旧草稿。仅跨周冲突状态改为三个正文框可聚焦、只读；关联目标、下一步修改、保存仍禁用，明确放弃入口保留。普通初始化失败仍锁定表单，不能恢复过期创建指令。

既有跨周E2E增加「前往填写」聚焦、全选范围、Backspace不能修改正文与目标选择禁用断言。此轮不重复受沙箱配置阻塞的Linux Electron启动；本地只执行格式、类型、lint、build，真实交互结果以当前head的Windows CI为准。不新增截图或将Renderer观察当作原生验证。
