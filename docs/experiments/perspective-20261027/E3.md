# E3 · 短途查来源后保留目标历史开合

共同基线 `bfd46c08d8fd9403ac7ec3b9abe1a3d187a2f6ea`；产品起源 `a02175e6cf598f08f3c4d053cccb2cf85d42816c`。本候选独立，不包含 E1/E2/E4；只供 Draft 对照。

源码缺口：TodayGoalContext 局部 expanded 初始为 false，Today → 完整记录 → Today 重建后折叠；既有 E2E 在返回后再次点击 summary。假设：只保留开合，可减少查来源后的重复操作。

复用 UiSession 的内存阅读状态，按行动 ID + 目标 ID 配对；组件已有相同配对 key。跨页面或行动切换后回来保留各自状态；同目标的另一行动、另一目标互不继承。显式收起即忘记，重新展开仍重新查询；窗口关闭/重新打开、renderer reload 或新 UiSession 全部重置，不写数据库或偏好存储。只有成功读到记录/理解/困惑才记住开；空历史、失败、不匹配读取会忘记。返回时仍重新读，若历史已删，会呈现现有空态/失败态，并且下次不再自动展开；不缓存旧历史、不跳过现有查询校验。

复现：有历史的目标 → Today 展开 → 查看上次完整记录 → 导航返回 Today，应保持开合；同目标另一行动和无历史目标默认折叠。手动收起、往返后仍收起；重载后也折叠。准备记录草稿后重复路径，草稿应保留，返回后保存仍刷新上下文；纯阅读前后持久化列表应相同。默认折叠不发查询，恢复展开每次重新读取一次，键盘展开/收起不转移焦点。

反例：保持展开可能持续占屏；异步重新读仍会改变面板高度，未承诺逐像素或阅读光标恢复。本候选不另存滚动位置，不加返回按钮或导航栈。父级 native 应比较长历史、草稿往返、窄窗口滚动与焦点；若高度变化比少一次点击更干扰，保留基线。

本地验证与限制：运行 lint/types/build 与相关 UiSession 单元测试，结果在 PR 正文和交接中绑定 head。扩展 today-goal-context E2E 覆盖只读数据一致、恢复、跨行动隔离、空历史/不可用历史、收起与 renderer 重启寿命。当前容器已有已知 SUID sandbox 限制，不重试、不禁用沙箱；Electron/native 验收待父级，不能把新增测试视为已通过。
