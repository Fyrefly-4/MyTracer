# MyTracer

MyTracer 是一款本地优先的 Windows 个人行动与成长记录应用，帮助你把目标转化为可以开始的小行动，记录投入，并在中断后接着往前走。

不必每天完成所有计划。一次尝试、一点进展、一次主动休息，都可以如实留下。再次开始时，你可以找到之前做到了哪里，以及接下来想做什么。

## 界面预览

![MyTracer 主界面：今天页面、今日重点与行动详情](docs/resources/mainForm.png)

打开应用先从“首页”看看最近的近况，再进入“今天”继续一件小事；侧栏保留目标、例行、进展、数据与复盘工作区。

本轮界面调整采用统一的 notebook 窗口样式，保留侧栏图标；今天、目标与例行支持独立滚动的列表/详情，长记录提供分页，数据工具与筛选仍可展开使用。上图为早期界面示意，实际以运行版本为准。下一次发布拟定为 **v1.0.0**，这不是已发布声明；版本提案与发布步骤见[发布维护说明](docs/maintenance/RELEASE.md#本次-v100-版本提案)。

## 主要功能

- **推进目标**：保存想推进的事情，整理下一步，选择今日重点。今天做什么，由你决定。
- **轻量记录**：快速记下投入时间和行动情况，也可以留下成果、困惑，以及下次的起点。
- **安排例行**：为日常活动安排节奏，如实记录做了一点、达成目标或主动休息，给每一天留些余地。
- **回顾积累**：查看投入时间与行动记录，整理收获与困惑，通过轻量复盘找到接下来想调整的地方。
- **获取启动帮助**：难以开始时，主动请求 AI 帮你缩小下一步。建议可以接受、修改或拒绝。

## 首页与记录日历

- 首页最多展示 3 个活跃目标，按最近记录的发生日期排序；同日按目标更新时间、ID 稳定排序。当前下一步与记录片段来自本地已有数据，不生成 AI 摘要。
- “去今天继续”只打开行动，不自动加入今日重点、标记完成或新建记录；今天的例行也在右侧记录区打开，切换后可继续本次会话的草稿。
- 目标封面默认按首页当前排列显示“I、II、III”，不取标题首字。在目标的“编辑与管理目标 → 外观”中可保存 1–2 个字符的本机自定义标记；标记跟随目标，清空后恢复当前顺序，不改目标名称或排序。
- 日历默认最近 **12 周 / 有记录**，可切换 **半年（26 周）/ 按条数**。两个选项保存在本机应用偏好中，重启仍保留；不可用或无效时安全回退。
- 每格按记录的**发生日期**统计行动与例行记录，包括主动休息、未进行。亮起不等于完成，条数不是成绩；未来日期留空。点击日期可分页回看当天记录，再打开已有数据详情。
- 首页只是已有功能的入口；详细筛选、统计、编辑、删除仍在原工作区。读取失败会单独提示，不会伪装成“没有记录”。

## 日常使用

以学习 React 为例，一次使用可以很简单：

1. **明确目标**：保存“学习 React”，把下一步写成“尝试一个组件状态示例”。
2. **选择今天的行动**：将这一步加入今日重点，从能开始的部分做起。
3. **留下记录**：记下投入的时间，以及“理解了什么”“哪里还不清楚”；没有全部做完，也可以记录实际行动。
4. **下次接着来**：查看上次留下的困惑和下一步，继续尝试；需要时再请求 AI 启动帮助。

完成当前下一步后，可以在“目标 → 编辑与管理目标”的“选择当前下一步”下拉框中选择已有待行动，或选择“新建下一步…”展开表单，填写后点击“创建并设为当前下一步”。新建的行动不会自动加入今天，已有行动和记录会保留。

同样的方式也可以用于日常活动、个人项目和兴趣。即使中断一段时间，也能沿着之前的记录重新开始。

## 本地记录，按需 AI 帮助

日常记录保存在你的电脑上，可以随时查看、编辑和导出。不使用 AI，也能完成目标管理、行动记录与复盘。

当你卡在“接下来做什么”时，可以请求 AI 启动帮助。这项功能需要联网，会结合当前目标、相关的近期记录和你的输入向配置的 AI 服务获取建议。挑选适合自己的建议，按需要修改，再确认保存。

## 安装与使用

目前面向个人日常使用，支持 Windows x64。安装包通过项目的私有 GitHub Releases 分发，需要相应访问权限；当前安装包未签名。

安装与更新相关说明见[维护文档](docs/MAINTENANCE.md#按事项查找)。

## 本地运行

在 Windows 上准备符合 [package.json](package.json) `engines` 的 Node.js 和 npm，然后运行：

```powershell
npm.cmd ci
npm.cmd exec -- install-electron --no
npm.cmd run dev
```

首次安装依赖与下载 Electron 需要网络访问。

## 技术栈与开发

| 技术 | 用途 |
| --- | --- |
| Electron | Windows 桌面应用运行时 |
| React、TypeScript | 界面与应用代码 |
| Vite / electron-vite | 开发与构建 |
| SQLite、better-sqlite3 | 本地数据存储 |
| Vitest | 单元与集成测试 |
| Playwright | Electron 端到端测试 |

常用命令在仓库根目录运行：

| 命令 | 用途 |
| --- | --- |
| `npm.cmd run dev` | 启动开发应用 |
| `npm.cmd run build` | 构建应用 |
| `npm.cmd run verify` | 运行格式、代码规范、类型、单元、集成与端到端检查 |
| `npm.cmd run package` | 生成 Windows 安装包 |

端到端测试会启动 Electron，请在支持桌面应用运行的 Windows 环境中执行。更多构建与测试说明见[开发与维护](docs/MAINTENANCE.md#开发与验证)。
